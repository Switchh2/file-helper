# File Helper

파일을 살펴보고 정리할 항목을 고르는 데 도움을 주는 Windows 파일 관리 프로그램입니다.

## 만들려는 이유

파일이 쌓이면 무엇을 정리해도 되는지 하나씩 확인하기가 번거롭습니다. 파일 목록을 보기 쉽게 보여주고, AI가 정리 후보와 이유를 제안하면 사용자가 직접 판단할 수 있도록 만들고자 합니다.

## 구상 중인 기능

- 선택한 폴더의 파일을 이름·크기·종류·수정일 기준으로 확인
- AI 분석을 사용하면 정리 검토 순서와 짧은 설명 제공
- 계속 보관할 파일은 정리 후보에서 제외하고 별도의 보관함에서 확인

보관함은 파일을 실제로 옮기는 기능이 아니라 앱 안에서 보관 결정을 기록하는 방식으로 구상하고 있습니다. AI의 제안은 참고 정보이며, 중요한 파일인지 확실하지 않으면 판단을 보류합니다.

## 현재 상태

프로젝트를 시작하는 단계입니다. 위 기능은 계획이며 아직 구현되지 않았습니다. 기술 구성과 첫 구현 범위는 이후 확정합니다.

## 개발 기록

약 50시간의 개발을 목표로, 실제 작업 시간과 진행 내용을 기록할 예정입니다. 구현 결과뿐 아니라 시도한 방법, 막힌 부분, 선택한 이유와 확인 결과도 함께 남깁니다.

## 데이터 취급

이 저장소에는 코드와 개발 기록만 올립니다. 개인 파일, 실제 파일 목록·분석 결과, API 키는 포함하지 않습니다. 외부 AI에 전달할 정보와 사용자 확인 방식은 구현 전에 정합니다.
